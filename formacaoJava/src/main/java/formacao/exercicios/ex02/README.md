# Exercício 02 — Criando Objetos (`Pessoa` e `Carro`)

## 🎯 Objetivo
Aprender a usar as classes que estão no pacote `formacao.model` (`Pessoa` e `Carro`) para criar objetos na memória, preencher seus dados e exibi-los no console.

## 📝 O que fazer
Abra o arquivo `Exercicio02.java` e complete os `// TODO:` para:
1. Criar uma `Pessoa` usando o construtor com parâmetros (`nome`, `cpf`, `idade`, `telefone`).
2. Criar um `Carro` usando o construtor com parâmetros (`modelo`, `cor`).
3. Ligar o carro usando `setEstaLigado(true)`.
4. Imprimir no console o nome da pessoa, o modelo do carro e se o carro está ligado.

## ✅ Resultado esperado
Exemplo de saída no console:

```text
Pessoa: João
Carro: Fusca (Azul)
O carro está ligado? true
```
