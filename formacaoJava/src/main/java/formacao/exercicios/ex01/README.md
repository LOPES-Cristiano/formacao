# Exercício 01 — Primeiro Contato e Tipos Primitivos

## 🎯 Objetivo
Praticar a declaração de variáveis usando tipos primitivos (`int`, `double`, `boolean`) e `String`, além de exibir mensagens no console com `System.out.println`.

## 📝 O que fazer
Abra o arquivo `Exercicio01.java` e complete os `// TODO:` para:
1. Criar uma variável `String` chamada `nome` com o seu nome.
2. Criar uma variável `int` chamada `idade` com a sua idade.
3. Criar uma variável `double` chamada `altura` com a sua altura (ex: `1.75`).
4. Criar uma variável `boolean` chamada `gostaDeProgramar` com o valor `true`.
5. Imprimir essas informações no console no formato abaixo.

## ✅ Resultado esperado
Exemplo de saída no console (com seus próprios dados):

```text
Nome: Maria
Idade: 25
Altura: 1.68
Gosta de programar? true
```
