# Formação Java — Iniciantes

Trilha prática em **Java 25 (Maven)** para aprender lógica de programação e Orientação a Objetos do zero.

## 📁 Estrutura

- **`src/main/java/formacao/model/`**: Entidades do sistema (`Pessoa.java` e `Carro.java`).
- **`src/main/java/formacao/exercicios/`**: 50 exercícios progressivos (`ex01` a `ex50`).
  - Cada pasta possui um `README.md` (descrição + resultado esperado) e um `ExercicioXX.java`.
- **`src/main/java/formacao/Main.java`**: Classe principal para testes rápidos.

## 📚 Trilha de Exercícios

- **`ex01` – `ex08`**: Variáveis, tipos primitivos, operações matemáticas, casting e `String`
- **`ex09` – `ex16`**: Condicionais (`if/else`, `else if`, `switch`, operadores lógicos)
- **`ex17` – `ex24`**: Laços de repetição (`for`, `while`, acumuladores e contadores)
- **`ex25` – `ex30`**: Arrays e `ArrayList`
- **`ex31` – `ex36`**: Métodos (sem retorno, com parâmetros e com retorno)
- **`ex37` – `ex44`**: Orientação a Objetos usando `Pessoa` e `Carro`
- **`ex45` – `ex50`**: Desafios integradores (médias, buscas, filtros, validações e relatório)

## 🚀 Como executar

Abra o arquivo `ExercicioXX.java` na sua IDE (IntelliJ, VS Code ou Eclipse) e clique em **Run** no método `main`.
