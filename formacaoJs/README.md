# Formação JavaScript — Iniciantes

Trilha prática em **JavaScript (Node.js)** para aprender lógica de programação, funções, arrays e objetos do zero.

## 📁 Estrutura

- **`src/model/`**: Entidades do sistema (`Pessoa.js` e `Carro.js`).
- **`src/exercicios/`**: 50 exercícios progressivos (`ex01` a `ex50`).
  - Cada pasta possui um `README.md` (descrição + resultado esperado) e um `exercicioXX.js`.
- **`src/index.js`**: Arquivo principal para testes rápidos.

## 📚 Trilha de Exercícios

- **`ex01` – `ex08`**: Variáveis (`let`/`const`), operações matemáticas, conversão e `String`
- **`ex09` – `ex16`**: Condicionais (`if/else`, `else if`, `switch`, operadores lógicos)
- **`ex17` – `ex24`**: Laços de repetição (`for`, `while`, acumuladores e contadores)
- **`ex25` – `ex30`**: Arrays (`push`, `includes`, `splice`, iteração)
- **`ex31` – `ex36`**: Funções (parâmetros e retorno)
- **`ex37` – `ex44`**: Objetos e classes usando `Pessoa` e `Carro`
- **`ex45` – `ex50`**: Desafios integradores (médias, buscas, filtros, validações e relatório)

## 🚀 Como executar

No terminal, dentro da pasta `formacaoJs`, execute:

```bash
node src/exercicios/ex01/exercicio01.js
```
