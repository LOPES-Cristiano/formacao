# Formação JavaScript — Iniciantes

Bem-vindo(a) ao repositório de treinamento em JavaScript (Node.js)!

## 📁 Estrutura

- **`src/model/`**: Contém as entidades (`Pessoa.js`, `Carro.js`).
- **`src/exercicios/`**: Contém os 50 exercícios práticos (`ex01` a `ex50`).
  - Cada pasta tem um `README.md` (descrição + resultado esperado) e um `exercicioXX.js` para você resolver.
- **`src/index.js`**: Arquivo principal para testes rápidos.

## 🚀 Como executar um exercício

No terminal, rode:
```bash
node src/exercicios/ex01/exercicio01.js
```
