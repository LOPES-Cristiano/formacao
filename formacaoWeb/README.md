# Formação Web Completa (HTML + CSS + JavaScript)

Trilha completa para dominar desenvolvimento Front-end: manipulação de DOM, eventos, formulários, consumo de APIs, armazenamento local e construção de componentes reais.

## 📁 Estrutura

- **`exercicios/`**: 25 exercícios práticos (`ex01` a `ex25`).
  - Cada pasta possui um `README.md` (descrição + resultado esperado), `index.html`, `style.css` e `script.js`.

## 📚 Trilha de Exercícios

- **`ex01` – `ex04`**: Seleção no DOM, eventos de clique, `classList` e Dark Mode
- **`ex05` – `ex10`**: Inputs em tempo real, senha visível, validação de formulários e listas dinâmicas (To-Do e filtros)
- **`ex11` – `ex13`**: Componentes interativos (Modal acessível, Abas/Tabs e Accordion)
- **`ex14` – `ex16`**: Persistência com `localStorage` e temporizador (`setInterval`)
- **`ex17` – `ex19`**: Consumo de APIs REST com `fetch`, `async/await` (ViaCEP), loading e tratamento de erros
- **`ex20` – `ex25`**: Mini-aplicações (IMC, Conversor de Moedas, Carrossel, Toast, Carrinho e Dashboard CRUD)

## 🚀 Como executar

Abra o arquivo `index.html` do exercício no navegador (ou use a extensão **Live Server** no VS Code para recarregamento automático).
