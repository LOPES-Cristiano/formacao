# Formação HTML & CSS — Rápida

Treinamento prático e direto ao ponto para dominar estruturação de páginas (**HTML5**) e estilização moderna (**CSS3**).

## 📁 Estrutura

- **`exercicios/`**: 15 exercícios rápidos (`ex01` a `ex15`).
  - Cada pasta possui um `README.md` (descrição + resultado esperado), `index.html` e `style.css`.

## 📚 Trilha de Exercícios

- **`ex01` – `ex03`**: Estrutura HTML5, listas, links, imagens e tags semânticas
- **`ex04` – `ex06`**: Cores, fontes, Box Model (`margin`, `padding`, `border`) e botões com `:hover`
- **`ex07` – `ex08`**: Formulários acessíveis e tabelas estilizadas
- **`ex09` – `ex12`**: Flexbox, CSS Grid e responsividade com Media Queries
- **`ex13` – `ex15`**: Variáveis CSS (`:root`), posicionamento (`sticky`) e cartão de perfil completo

## 🚀 Como executar

Abra o arquivo `index.html` do exercício diretamente no navegador (ou use a extensão **Live Server** no VS Code).
