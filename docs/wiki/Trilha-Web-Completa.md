# 🌐 Trilha Web Completa (HTML + CSS + JS) — 25 Exercícios

Aqui é onde tudo se conecta! Você vai transformar páginas estáticas em **aplicações web interativas** que respondem ao usuário, salvam dados e consomem APIs reais.

---

## 🎯 Módulo 1: DOM e Eventos (`ex01` – `ex04`)
- **O que você aprende:** `document.querySelector`, `addEventListener`, `classList.toggle` e **Dark Mode** com variáveis CSS.
- **💡 Usos reais:** Alternadores de tema, contadores de carrinho, menus interativos.

## 📝 Módulo 2: Formulários e Listas Dinâmicas (`ex05` – `ex10`)
- **O que você aprende:** Evento `input` em tempo real, mostrar/ocultar senha, validação com `preventDefault()`, `createElement` e filtro de busca.
- **💡 Usos reais:** Barras de pesquisa instantânea, formulários de checkout, listas de tarefas.

## 🧩 Módulo 3: Componentes de UI (`ex11` – `ex13`)
- **O que você aprende:** **Modal acessível** (fechar no X e na tecla `ESC`), **Sistema de Abas (Tabs)** e **Accordion (FAQ)**.
- **💡 Usos reais:** Componentes presentes em praticamente todo sistema web e SaaS.

## 💾 Módulo 4: Persistência e Tempo (`ex14` – `ex16`)
- **O que você aprende:** `localStorage` (`JSON.stringify` / `JSON.parse`) e temporizadores (`setInterval` / `clearInterval`).
- **💡 Usos reais:** Salvar preferências do usuário e rascunhos sem precisar de banco de dados; cronômetros e contagens regressivas.

## 🌍 Módulo 5: APIs REST com `fetch` (`ex17` – `ex19`)
- **O que você aprende:** `fetch`, `async/await`, consumo da API **ViaCEP**, renderização de listas externas, estado de *Loading* e `try/catch`.
- **💡 Usos reais:** Preenchimento automático de endereço em cadastros, integração com qualquer back-end (Java, Node, etc.).

## 🚀 Módulo 6: Mini-Aplicações (`ex20` – `ex25`)
- **O que você aprende:** Calculadora de IMC, Conversor de Moedas, Carrossel de Imagens, Notificações Toast, Carrinho de Compras e **Dashboard CRUD completo**.
- **💡 Usos reais:** Portfólio prático para vagas de Desenvolvedor Front-end Júnior!
