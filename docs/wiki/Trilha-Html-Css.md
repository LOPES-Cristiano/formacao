# 🎨 Trilha HTML & CSS — 15 Exercícios

Trilha rápida e prática para dominar a construção de interfaces modernas e responsivas.

---

## 🏗️ Módulo 1: HTML5 Semântico (`ex01` – `ex03`)
- **O que você aprende:** Estrutura básica, headings, listas (`<ul>`, `<ol>`), links, imagens com `alt` e tags semânticas (`<header>`, `<main>`, `<footer>`).
- **💡 Usos reais:** SEO (ranqueamento no Google) e acessibilidade para leitores de tela.

## 🎨 Módulo 2: CSS3 e Box Model (`ex04` – `ex06`)
- **O que você aprende:** Cores, tipografia, `margin`, `padding`, `border`, `border-radius`, `:hover` e `transition`.
- **💡 Usos reais:** Criação de cards de produtos, botões interativos e identidade visual de marcas.

## 📝 Módulo 3: Formulários e Tabelas (`ex07` – `ex08`)
- **O que você aprende:** `<form>`, `<label>`, `<input>`, `<textarea>`, `<table>` estilizada.
- **💡 Usos reais:** Telas de login, cadastro de clientes, tabelas de preços e relatórios.

## 📐 Módulo 4: Layouts Modernos e Responsividade (`ex09` – `ex15`)
- **O que você aprende:** **Flexbox** (navbars e centralização), **CSS Grid** (galerias de cards), **Media Queries** (celular vs desktop), variáveis CSS (`:root`) e `position: sticky`.
- **💡 Usos reais:** Qualquer site moderno (landing pages, portfólios, dashboards responsivos).
